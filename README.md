## ✨ 功能亮点

约 50 项 PDF 处理功能，全部在本机完成，**不上传任何文件内容**：

### ⭐ 流式编辑器

像编辑文档一样编辑 PDF：

- 预览 / 编辑双模式，文字可选、可搜索
- **真·文本编辑**：修改文字后自动折行重排，输出仍可搜索
- 扫描页自动 OCR，识别结果直接可编辑
- 文字 / 图片 / 高亮 / 遮盖等对象编辑，支持撤销重做
- 全文查找替换，一键批量替换

### ✏️ 编辑

预览编辑 · 批注管理 · 页眉页脚 · 页码设置 · 文档背景

### 📄 页面管理

合并 · 拆分 · 插入 / 替换 · 旋转 / 删除 / 重排 · 裁剪 / 缩放 · 分割组合 · 书签管理 · 内容提取

### 🔄 转换

PDF ↔ 图片 · PDF 转 Word · 电子书转 PDF · PDF 压缩 · 双层 PDF（可搜索）· AI 制卡

### 🔒 保护

水印添加 / 去除 · 加密 / 解密 · 签名检测 · 元数据管理

### 🖼 图像工具

图片压缩 · 格式转换 · 裁剪 · 拼接 · 图标制作（批量处理）

## 🔒 隐私与安全

- **全程离线**：OCR 识别、编辑、转换均在本地完成，不联网
- **数据不留存**：不收集用户数据，不上传文件内容

## ❓ 常见问题

**Q：安装包被杀毒软件拦截 / 报未签名？**
安装程序暂未做代码签名，可能触发部分杀毒软件提示，添加信任后即可正常使用。

**Q：下载速度慢？**
GitHub 下载速度因运营商而异，可稍后重试或更换网络。

**Q：如何升级？**
应用内会自动检测新版本并提示；也可随时到 [Releases 页面](https://github.com/leebeep/PDFMaster-Release/releases/latest) 手动下载覆盖安装。

**Q：需要联网吗？**
不需要，所有功能均可离线使用。
